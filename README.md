# Travel with Mkay, redesign preview (v3)

Preview of a redesigned travelwithmkay.co.ke (Maria Kamau, travel coach, Nairobi), in the live site's own style
(Playfair Display, Lato, Tangerine, navy, terracotta, golden, sand) with a proof-led layout and full content parity.

Pages: home, services (coaching.html redirects here), client stories, podcasts, about, travel tools, learn.

- Every page is `noindex` so this preview never competes with the live site in search.
- Booking buttons go to the live booking pages; podcast "Read the feature" links go to the live feature pages.
- `assets/video/meet-maria.mp4`: Maria's own voice from her 29 Aug 2026 webinar over her travel photos.
- Client clips are highlight cuts of testimonials from her 2026 webinars, with burned-in captions and WebVTT.
- Earlier versions: git tags `v1-rejected` and `v2-live-style`.
