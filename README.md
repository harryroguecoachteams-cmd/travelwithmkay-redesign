# Travel with Mkay, redesign preview

Static preview of a redesigned travelwithmkay.co.ke (Maria Kamau, travel coach, Nairobi).
Five pages: home, coaching, client stories, learn, about. Plain HTML, CSS and a little JS.

- Every page is `noindex` so this preview never competes with the live site in search.
- Booking buttons go to the live booking pages on travelwithmkay.co.ke.
- Client videos in `assets/video/` are highlight cuts of testimonials given on Maria's
  2026 webinars (17 Jun, 29 Aug, 6 Oct), with burned-in captions and WebVTT files.
