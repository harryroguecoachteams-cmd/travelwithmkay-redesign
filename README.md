# Travel with Mkay, redesign preview (v4)

Preview of a redesigned travelwithmkay.co.ke (Maria Kamau, travel coach, Nairobi), in the live site's own style
(Playfair Display, Lato, Tangerine, navy, terracotta, golden, sand).

v4 is the v2 layout plus the v3 pieces that were picked in review: the credibility band with moving press and
podcast logos, the client story theater, the offer tabs, the 1989 / country 100 photo pair above the map, the free
travel kit band, the two-column FAQ, the closing call to action and the footer links. The AI comparison is gone.

Pages: home, services (coaching.html; services.html redirects to it), client stories, podcasts, about, learn, travel tools.

- Every page is `noindex` so this preview never competes with the live site in search.
- Booking buttons go to the live booking pages; podcast "Read the feature" links go to the live feature pages.
- Client clips are highlight cuts of testimonials from her 2026 webinars, with burned-in captions and WebVTT.
- Earlier versions: git tags `v1-rejected`, `v2-live-style` and `v3-proof-led`.
